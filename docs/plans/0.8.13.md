## Release flow (from v0.8.12)

The v0.8.12 release used this flow (found from `git show 5a6665c`, `git tag -v v0.8.12`, `.github/workflows/release.yml`, `git reflog`):

1. **Version bump**: the version is injected at build time via goreleaser
   ldflags (`-X .../buildinfo.Version={{ .Tag }}`); no source-file version
   literal to bump. The release commit (`5a6665c`) only touched
   `CHANGELOG.md`: turning `[Unreleased]` into `[0.8.12] - <date>` with the
   release notes. Files: `internal/buildinfo/buildinfo.go:15` (`Version = "dev"`),
   `.goreleaser.yaml` (ldflags).

2. **Merge to master**: `work/0.8.12` was fast-forward merged into `master`
   (`git reflog master`: `merge work/0.8.12: Fast-forward`). No merge commit;
   the release branch commits became master's history directly.

3. **Push**: push `master` to `origin/master`.

4. **CI on the pushed SHA**: every CI workflow on the exact pushed SHA must
   be green (`.github/workflows/ci.yml`, `govulncheck.yml`). The release
   workflow (`release.yml`) does NOT run on a branch push — only on a tag
   push (`on: push: tags: ["v*"]`).

5. **Tag**: create a signed annotated tag `v0.8.13` on the exact green SHA:
   `git tag -a v0.8.13 -m "Wakil v0.8.13" <sha>`. The tag is SSH-signed
   (same as v0.8.12: `git tag -v v0.8.12` shows an SSH signature). Push only
   the tag: `git push origin v0.8.13`.

6. **Release workflow**: the tag push triggers `release.yml`:
   - `sandbox-image`: builds, pushes and signs the sandbox image; exposes
     its digest.
   - `release`: builds + signs + publishes the goreleaser release, injecting
     the image digest. Release notes come from the CHANGELOG section
     (`scripts/release_notes.sh <version>`). Creates the GitHub release with
     artifacts (`dist/*.tar.gz`, `*.deb`, `*.rpm`, `*.apk`, `checksums.txt`,
     `install.sh`, `config.quickstart.json`).
   - `smoke`: installs the published packages and checks `wakil version`
     reports the tag and the pinned digest.

7. **Verify**: `git tag -v v0.8.13`; check the release page, artifacts, and
   `checksums.txt`; read-only check that `install.sh` at `releases/latest`
   resolves to v0.8.13 and pins hisn 0.6.7.
